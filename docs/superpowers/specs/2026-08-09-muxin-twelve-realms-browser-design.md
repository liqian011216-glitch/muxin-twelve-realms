# 牧心十二境｜横屏浏览器版设计

## 目标与范围

面向横屏浏览器（电脑与展厅触摸屏）的 7–9 分钟沉浸式叙事体验。以现有十二张 16:9 场景图为主视觉，暂不接入 Godot 或其他游戏引擎。

用户在由“执”到“空”的十二境中做出少量有意义的动作；系统将这些动作映照为一张禅意人格签。结果只描述本次游历中的应对倾向，不作心理诊断或固定人格判定。

首版不登录、不收集个人资料；音频不作为首版验收前提。

## 核心体验

互动必须逐境减少：前半段用户通过拖拽和选择试图控制牛；中段学习停留、回望与松开；后半段只需顺势移动、聆听和静候；终局允许用户不做任何操作。

失败状态不存在。每种选择都改变后续的画面回应和心行记录，但都可抵达心月图。

## 页面与互动节奏

| 段落 | 境 | 互动方式 | 叙事目的 |
|---|---|---|---|
| 执 | 未牧、初调、受制 | 拖拽绳索、追近、取舍 | 体验用力控制的阻滞 |
| 转 | 回首、驯服、无碍 | 减速、回看、松开 | 感知控制以外的可能 |
| 忘 | 任运、相忘、独照 | 顺势、跟随、停留 | 进入自在同行 |
| 空 | 双忘、禅定、心月图 | 静候、拓印 | 让任务意识退出 |

### 十二境节点

1. **未牧**：擦开或点击开场拓印，按住并拖动绳索追牛。拖得过急时，牛离得更远。
2. **初调**：用户停留在合适距离，牛才回首；强化“先观察”。
3. **受制**：选择“拉紧 / 松一点 / 解开”。
4. **回首**：向左轻拖回看虎影、山径与来处，或继续前行。
5. **驯服**：以短句呈现人牛关系由对抗转向理解；不设强操作。
6. **无碍**：选择继续握绳、挂绳于石、任牛饮泉。
7. **任运**：选择替牛选路、跟随蹄印或看它自己前行。
8. **相忘**：以停留与听笛为主；界面弱化进度信息。
9. **独照**：慢速跟随月光或牛迹；不设障碍、计时或跳跃玩法。
10. **双忘**：撤去按钮和操作提示，静候自动转场。
11. **禅定**：以短暂停留触发空白与月光过渡。
12. **心月图**：选择拓印牛、来路或空白，生成禅意人格签。

## 视觉与界面

- 画布恒为 16:9 全屏，不出现页面滚动。
- 底层使用制作包的十二张 PNG；中层仅做绳、雾、月光、墨迹等轻量动态；上层放境名、极短文案与必要提示。
- 选择项呈题刻/水墨浮签，不使用常规卡片和按钮框。
- 前半段转场可有拉扯、风雨、墨线；中段使用流水和雾化；后半段转为白场、月光与留白。
- 第八境起逐步淡出章节进度与显式 UI；第十境起不再显示操作提示。

## 心行记录与人格签

系统不展示分数，只累计四种心行：

| 心行 | 常见行为 | 主签 |
|---|---|---|
| 持 | 拉紧、追近、抢先决定 | 持绳签 |
| 观 | 停留、回看、聆听 | 观照签 |
| 和 | 等待、配合、并行 | 同行签 |
| 放 | 松手、留白、顺势 | 任运签 |

每个有效选择给一至两种心行加权；越接近终局的选择权重越高。最终按最高权重生成主签；前两项接近时附带转签文案，例如“持绳而能回首”或“同行终至任运”。

四种签均包含朱砂印面、签名、优势描述、当下提醒和一句偈语式短文：

- **持绳签**：行动快、愿意担责；提醒“有时不必独自用力”。
- **观照签**：善感知与理解；提醒“看清之后，也可迈出一步”。
- **同行签**：重关系与节奏；提醒“等待也是一种主动”。
- **任运签**：信任过程、容纳不确定；提醒“放手不等于放弃”。

结果页标题为“你此刻所持的一签”，副句为“它不定义你，只映照你走过的这一程”。用户可保存签图或重新游历。

## 内容、组件与数据流

每一境由独立内容配置描述：背景图、短文、互动类型、可选项、心行权重、画面反馈与转场。页面渲染器只读取当前境配置；状态模块汇总心行并负责恢复当前游历；签模块只读取最终汇总结果。

```text
场景配置 → 画面与互动渲染 → 用户动作 → 心行状态
                                           ↓
心月图拓印 ← 人格签生成 ← 最终权重与转签规则
```

未来接入 Godot 时，游戏只需返回同一套 `持 / 观 / 和 / 放` 行为事件；网页场景、人格签与结尾不重做。

## 异常与边界

- 缺失或加载失败的画面显示淡纸底和“重试 / 继续”入口，不丢失已记录的心行。
- 拖拽、键盘与触摸输入均可触发核心互动；触摸屏不依赖悬停。
- 用户刷新页面时恢复到最近完成的境；重新游历才清空状态。
- 任何未完成互动可在短暂停留后提供“顺势前行”，保障展厅体验不中断。

## 验收标准

1. 从开场到心月图的任一选择路径均可完成，时长约 7–9 分钟。
2. 横屏浏览器无纵向滚动、无被裁切的文案或控件。
3. 后四境的显式 UI 和动作明显少于前四境。
4. 同一浏览器以不同选择走完，能稳定得到不同主签或转签。
5. 结果呈现为禅意人格映照，不含百分比、排名、优劣评价或医学/心理诊断式表述。
6. 第一版不依赖 Godot、登录、网络账号或个人数据采集。
