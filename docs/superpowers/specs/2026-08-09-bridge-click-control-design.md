# 独木桥点击平衡交互设计

## 目标

让独木桥适合鼠标和触屏操作，玩家通过点击左右区域修正人物重心，完成过桥。

## 交互规则

- 点击桥面左侧：施加一次向左的重心修正。
- 点击桥面右侧：施加一次向右的重心修正。
- 不使用按住、拖拽或必须持续按键的操作。
- 键盘左右键保留为桌面端备用操作。
- 界面提示统一为“点击左右两侧，保持平衡”。

## 游戏逻辑

- 人物持续向桥尾前进，但只有在平衡状态较好时进度才正常增加。
- 点击修正会影响 `player_lean`，并与牛的随机摆动共同计算最终倾斜角。
- 每次重新开始时，进度、倾斜、失败状态和计时全部归零。
- 失衡后显示“落水了，从桥头重新开始”，短暂延迟后重新开始一轮。
- 结算按钮统一使用“再走一次”，避免误导为进入下一境。

## 验收标准

- 点击左、右区域都能看到人物倾斜方向发生对应变化。
- 不点击时不能稳定自动通关；平衡差时进度明显变慢或落水。
- 点击“再走一次”后时间显示从 0 秒重新开始。
- 失败提示可见，且重新开始后人物回到桥头。
- Web 导出后鼠标点击和触屏点击均可操作。
