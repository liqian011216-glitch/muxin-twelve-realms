# 拓印柔边不规则显影设计

日期：2026-08-16  
状态：用户已确认设计，等待书面规格复核

## 目标

修正拓印第 3 步“拓包上墨”的方块式显影。玩家每次轻点宣纸时，应出现接近真实拓包拍拓的柔边、不规则墨迹；多次墨迹自然叠加，逐渐显出完整石刻。

## 范围

本次只修改拓印第 3 步的显影效果与完成判定。

保持不变：

- 第 1 步“清扫石面”；
- 第 2 步“铺上宣纸”；
- 现有石刻、宣纸、拓包和界面美术；
- 玩家先选择右侧拓包，再点击中央宣纸的操作顺序；
- 没有倒计时、没有失败；
- 完成后显示最终拓印并自动继续的流程。

## 玩家体验

1. 覆纸完成后，右侧拓包变为可操作。
2. 玩家点击拓包，再轻点宣纸。
3. 每次点击以触点为中心生成一片柔边、不规则墨迹。
4. 墨迹具有轻微颗粒、浓淡变化，并在有限范围内随机改变大小、角度和轮廓；墨迹不会偏离玩家点击区域。
5. 相邻墨迹自然重叠，不出现矩形接缝、规则网格或整块方形显影。
6. 有效显影覆盖达到约 85% 时，剩余部分以短暂柔和过渡补全，随后显示完整拓印。
7. 完成后沿用现有约 1.2 秒停留和完成信号。

## 技术设计

### 显影遮罩

用一张低分辨率动态灰度遮罩控制最终拓印图的可见区域。遮罩初始为黑色；每次点击向遮罩写入若干相互重叠的柔边墨斑。最终拓印图通过 CanvasItem Shader 采样遮罩，按遮罩亮度显示对应像素。

每次墨斑由多个略有偏移的椭圆衰减叠加形成，并加入低强度颗粒扰动。随机数使用固定种子，使同一次实现的视觉稳定、测试可复现，同时不同点击仍呈现自然差异。

### 覆盖率

覆盖率由遮罩中达到有效显影阈值的像素比例计算，不再使用 6×4 矩形格。达到 85% 即进入完成状态，避免玩家寻找细小未覆盖空隙。

### 输入

保留单次轻点拍拓，不改为连续拖动。鼠标点击和手机触控都映射到宣纸局部坐标，坐标超出宣纸区域时不计入覆盖率。

### 完成过渡

达到 85% 后停止接收新的拍拓输入。遮罩在短暂过渡中补至完全显影，然后沿用现有完成文案、最终作品和完成信号。重复输入不能重复发送完成信号。

## 异常与重置

- 点击宣纸外部：不生成墨迹，不增加进度。
- 未选择拓包时点击宣纸：不生成墨迹。
- 点击“重置”：遮罩、覆盖率、随机序列和完成状态全部回到初始值。
- 浏览器尺寸变化：遮罩使用宣纸局部坐标，不因页面缩放改变点击对应位置。

## 验收标准

- 任意一次点击形成的可见边缘均不是矩形。
- 连续点击后不出现 6×4 网格或方块接缝。
- 墨迹中心与玩家触点一致，允许的随机变化只发生在触点附近。
- 进度按真实遮罩覆盖率增长。
- 覆盖达到约 85% 后能稳定自动补全并完成。
- 鼠标与手机触控均能完成拍拓。
- 清扫、覆纸、重置和完成信号不受影响。
- Godot Web 导出能够在当前本地网页预览中显示相同效果。
