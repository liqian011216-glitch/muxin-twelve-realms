# 《牧心十二境》现有成果盘点

日期：2026-08-16
盘点原则：复用优先；没有验证现有内容不满足最终规格，不从零重做。

## 1. 结论

当前项目并不是需要从零开发的空项目。可直接复用或保留后小改的内容包括：首页及开场视觉、十二境的整体美术方向、固定牧人与水牛设定、拓印、寻牛、独木桥、莲花跳跃的视觉素材、统一 Godot 入口、Web 构建框架、旅程和签文的部分数据模型以及 46 项现有自动化契约测试。莲花跳跃的现有玩法代码面向电脑网页且 Bug 较多，不列入玩法复用范围。

真正缺少的是这些成果之间的完整连接、最终命名和规则对齐、十二境逐境动画、游戏结果回传、进度恢复、匿名后台、正式牧心签页面、资源压缩及公开发布。

## 2. 已验证的技术基线

- Web 项目能够成功完成 vinext production build。
- Web 测试：27 项通过，0 项失败。
- Godot 脚本契约测试：19 项通过，0 项失败。
- 当前已有一个包含四个互动场景的统一导出目录：`web/public/games/godot`。
- 同时还保留四个重复独立导出目录，造成 `web/public/games` 总体积约 1.6GB。
- 五份导出各约 314～325MB；统一包已经存在，后续重点是验证后保留统一包、优化资源和删除重复副本，而不是重新编写四个游戏。
